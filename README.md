# Ultimate Skyblock

**Free Java Edition downloads · Minecraft 26.3 · Fabric · Solo or co-op**

Build a home over the void, turn scarce resources into working farms, and grow
as a crew through shared quests, five skills, void fishing and expeditions.
Designed around challenging hardcore play for two or three friends; solo play
is supported. Player feedback helps decide what improves next.

**[Download the latest release](https://github.com/TorMartin-ops/ultimate-skyblock-downloads/releases/latest)** ·
**[Report a bug or share balance feedback](https://github.com/TorMartin-ops/ultimate-skyblock-downloads/issues/new/choose)**

## Start playing

- **Windows, official Minecraft Launcher:** download the `-client.zip`, extract
  everything, close Minecraft and the launcher, and run `Install.bat`.
- **Windows, macOS or Linux, Modrinth App / Prism Launcher:** download the
  `.mrpack` and import it as a new instance. Use Java 25.
- **Already have Fabric?** Use the release JAR with Fabric API for Minecraft 26.3.
  Fabric Loader 0.19.5 and Java 25 are the tested setup.

Create a world with **World Type: Skyblock**, structures enabled, and **Hardcore**
for the intended experience. Friends need the same Ultimate Skyblock version.
Minecraft is purchased and authenticated separately through your launcher.

[Portable setup](modpack/PORTABLE.md) · [Hosting](docs/HOSTING.md) · [Included mods](docs/MODS.md)

## What you build toward

- A tiny island with one ice, one lava bucket, an oak tree and a sapling.
- Real biome regions over the void, small islets, structure farm locations,
  floating Nether structures and expeditions toward the End.
- Catalyst generators, resource farms and shared quest milestones that improve
  the crew's generators. No AFK penalties are enabled by default.
- Mining, Fishing, Foraging, Farming and Slaying skills; creature studies reward
  useful materials, and void alchemy connects resource conversions.
- Void fish, bait, salvage, records, co-op catches and rare fishing encounters.
- Named visitors, a Hitching Post, bounties, shared reward choices and collection goals.
- Costly co-op revival, run history and restart options. Losing your only lava
  can still end a run: the start deliberately has consequences.
- Silk Touch transport for ordinary and trial spawners.

## Small companion set

The default client has **ten mod files**: Ultimate Skyblock, Fabric API, Sodium,
Lithium, FerriteCore, ImmediatelyFast, Entity Culling, AppleSkin, Jade and
Shulker Box Tooltip. Only the first two are mandatory. The other eight improve
performance or show useful information. Fabric's internal modules make the
in-game mod count higher than ten; that is expected.

## First controls

**K:** Skills. **Tap G:** regular perk action. **Hold G for 0.6 seconds:** charged
level-10 capstone. Timber! grows saplings; Feller fells trees.
Use `/skyblock guide`, `/skyblock notes` and `/skyblock rewards` for the guide,
perk details and pending team rewards. Rebind keys in Minecraft's controls.

## Help shape the pack

This is an actively developed public playtest. Report confusing instructions,
unrewarding milestones, crashes and exploits as well as what you enjoyed.
Include version, OS, crew size, elapsed play time and the relevant skills/farm
setup. For bugs, include repeatable steps and sanitized log excerpts.
**Never upload launcher account files, tokens or your entire game folder.**

Native macOS input and long-session balance still need broader player testing.
Automated tests do not prove the pack is bug-free. 2.8.5 changes distribution,
licensing and documentation; gameplay is unchanged from 2.8.4.
