# Voidhome 3.3.1

The mod has a new name: Voidhome. It was called Ultimate Skyblock until now. Nothing in the gameplay changed.

- The mod list, the `/skyblock` menu and the key binding categories say Voidhome
- The file is now `voidhome-3.3.1.jar`
- The mod id, the commands and the config are the same, so your worlds and settings keep working

If you put the jar in your mods folder by hand, remove the old `ultimate-skyblock-3.3.0.jar`. Two jars of the same mod stop the game from starting.
